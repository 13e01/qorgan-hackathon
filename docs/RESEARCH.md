# Исследование: что важно для QORGAN

Дата доступа ко всем источникам — 28.10.2026. **[факт]** — со страницы источника; **[непроверено]** — только сниппет поиска или вторичный пересказ; **[вывод]** — наше заключение. Полный рабочий отчёт с дополнительными ссылками хранился вне репозитория; здесь — то, что повлияло на решения.

> Станции QORGAN (Сергеевка → Явленка → Петропавловск → Соколовка) — учебные. Реальные цифры ниже нужны для масштаба задачи, а не как данные системы.

## 1. Актуальность для СКО

- **7.04.2024:** Сергеевское водохранилище заполнено на 163 %; «высокая вода» придёт в Петропавловск **через 7–8 дней**; под угрозой до 845 домов. [факт] [bizmedia.kz](https://bizmedia.kz/2024-04-07-cherez-7-ili-8-dnej-pavodki-dojdut-do-petropavlovska/md/)
- **27.04.2024 (акимат и ДЧС СКО):** затоплено **3 898 домов** и 6 597 дачных участков, эвакуировано **14 388 человек**; уровень Есиля в Петропавловске **1 316 см** (в 2017 г. — 1 267 см). [факт] [bizmedia.kz](https://bizmedia.kz/2024-04-28-na-severe-kazahstane-proshel-pik-vtoroj-volny-pavodkov/), [zakon.kz](https://www.zakon.kz/redaktsiia-zakonkz/4858246-v-sko-stihiya-otsutpaet-rgp-kazgidromet.html)
- **По стране (07.06.2024):** затоплено 11 998 домов, 6 875 не подлежат восстановлению, на жильё нужно около **237 млрд тг**. [факт] [Kazinform](https://qazinform.com/news/kazakh-president-briefed-on-governments-work-to-address-impact-of-floods-7e8fd1)
- **МЧС, 15.04.2024:** эвакуировано 111 194 человека по стране. [факт] [Astana Times](https://astanatimes.com/2024/04/kazakhstan-evacuates-over-111000-people-since-beginning-of-floods/)
- **2026:** Казгидромет относит СКО к регионам с наибольшей вероятностью паводка, «особый контроль» — ниже Сергеевского водохранилища. [факт] [Tengrinews](https://en.tengrinews.kz/kazakhstan_news/flood-forecast-for-2026-which-regions-of-kazakhstan-are-at-271125)
- **Распространение волны:** в 2017 г. пик на Сергеевском водохранилище — 18.04, в Петропавловске — 28.04 (≈ 10 суток) [факт по датам, вывод о разнице]; в бюллетене 17.04.2024 окна пиков сдвигаются по створам примерно на неделю. [факт] [Казгидромет](https://kazhydromet.kz/en/post/2614)

**Влияние на проект:** время добегания волны — реальный и измеримый ресурс заблаговременности. Это обосновало выбор главной функции (прогноз по реке). Задержки в учебной модели сжаты (51 + 51 + 17 ч) — это сказано в интерфейсе и документах.

## 2. Что делают профессиональные системы

| Система | Что важно | Источник |
|---|---|---|
| Казгидромет | 442 гидропоста, уровень 2 раза в сутки, еженедельные прогнозы в половодье; прогноз — окна дат пика по створам | [факт] [kazhydromet.kz](https://kazhydromet.kz/en/gidrologiya/o-gidrologii) |
| GloFAS (Copernicus) | ансамбль 51 член на 15 суток; пороги — периоды повторяемости 2/5/20 лет; вероятность превышения; время до пика; дальние сроки показываются бледнее | [факт] [ECMWF Confluence](https://confluence.ecmwf.int/spaces/CEMS/pages/265028831/GloFAS+Hydrological+Products+Overview) |
| EFAS | регулярная проверка по заблаговременности против persistence («трудно побить») | [непроверено] [EFAS](https://european-flood.emergency.copernicus.eu/en/node/732) |
| Google Flood Hub | надёжность до 5 суток на водосборах без постов | [факт] [Nature 627, 2024](https://www.nature.com/articles/s41586-024-07145-1.pdf) |
| WMO EW4All | 4 столпа: знание риска · мониторинг и прогноз · оповещение · готовность | [факт] [wmo.int](https://wmo.int/site/wmo-and-early-warnings-all-initiative) |
| CAP v1.2 | жизненный цикл оповещения Alert/Update/Cancel, Ack, severity/urgency/certainty | [факт] [OASIS](https://docs.oasis-open.org/emergency/cap/v1.2/CAP-v1.2-os.html) |

**Чего обычно нет в прототипах** [вывод]: заблаговременность в днях, проверка прогноза, показ неопределённости, жизненный цикл тревоги (подтверждение оператором).

**Влияние на проект:**
- прогноз по реке с **проверкой против persistence** и долей фактов в диапазоне (как EFAS, в упрощённом виде);
- **диапазон** и самый ранний/поздний срок вместо одной линии; честная пометка, что это не доверительный интервал;
- предупреждения с **жизненным циклом**: открыто → обострение/снижение → снято, отметки оператора с автором и комментарием, повторное «Новое» при обострении;
- пороги называются «предупредительный/опасный» и помечены как учебные (периодов повторяемости у учебной модели нет).

## 3. Методы гидрологии

- **NWS Lag-and-K:** гидрограф сдвигается на лаг и сглаживается; параметры подбираются по историческим паводкам. [непроверено] [weather.gov](https://www.weather.gov/media/owp/oh/hrl/docs/24lagk.pdf)
- **Маскингам** S = K[X·I + (1−X)·O], 0 ≤ X ≤ 0,5; калибровка по парным постам; параметры действуют только в диапазоне калибровки. [факт] [Ponce, SDSU](https://ponce.sdsu.edu/enghydro/engineering_hydrology_09.php)

**Влияние:** QORGAN-ROUTE-1 — упрощённый lag-and-attenuate с поправкой по текущей ошибке; в документах прямо сказано, что параметры учебные и для реки нужна калибровка.

## 4. Дизайн: Microsoft Fluent 2

Официальные материалы: [fluent2.microsoft.design](https://fluent2.microsoft.design/design-principles), значения токенов — из исходников [@fluentui/tokens](https://github.com/microsoft/fluentui/tree/master/packages/tokens). [факт]

| Правило Fluent 2 | Как в QORGAN |
|---|---|
| Сетка 4 px, отступы 4…56 | токены `--sp-*`, кратные 4 (было с T4.1) |
| Body 14/20, заголовки semibold, sentence case | `--fs-base` 14,5 px, заголовки 600, без капса |
| Нейтральные поверхности, бренд-цвет точечно (CTA, выбранное) | синий только у главных кнопок и выбранного пункта |
| Семантические цвета только для статусов и всегда с текстом/иконкой | риск всегда «цвет + слово»; предупреждения — полоса + бейдж + текст |
| Тени: двухслойные, малые для карточек | `--shadow-sm` у карточек, `--shadow-lg` у уведомлений |
| Движение 150–250 мс, `prefers-reduced-motion` | `--dur` 220 мс, отключение анимаций по системной настройке |
| Контраст 4.5:1, фокус, aria-live, без горизонтальной прокрутки | видимый фокус, aria-live у ленты и уведомлений, 375 px без прокрутки |

**Влияние:** интерфейс T4.1 уже соответствовал большинству правил, поэтому полная перерисовка не делалась (CLAUDE.md: «не переписывать работающее без обоснования»). Новые экраны (предупреждения, администрирование, прогноз по реке) сделаны на тех же токенах. Mica/Acrylic и вид Windows не копировались.
