### 2026-10-28 — T2 Модуль оценки риска
- Сделано: `packages/shared/src/risk` — очистка данных, окно с обрезкой по разрыву, фильтр выбросов, МНК-тренд с SE, ускорение/замедление, прогноз на 3 ч, ETA с диапазоном и пределом 72 ч, 5 факторов с баллами, категория, причины, качество данных; коэффициенты из `risk_config` с подстановкой значений по умолчанию. Backend: `apps/server/src/risk/service.ts` (данные из БД, оценка верхней станции для фактора волны, оценка на прошлый момент без будущих данных), API `GET /api/stations/:id/risk`, `/risk/explanation` (гость), `/forecast` (оператор). Проверочные данные `npm run db:fixture` (TEST_FIXTURE, не симулятор).
- Проверено: `npm test` — 82 теста (46 модуль риска, 36 сервер, включая все тесты T1); `npm run typecheck` — 0 ошибок; вручную на сервере: 4 станции дают HIGH/MEDIUM/LOW/MEDIUM как в тестах, гость к прогнозу → 401, оценка на 06:00 → ETA 4,5 ч, неизвестная станция → 404.
- Аудит: деления защищены, NaN/Infinity не попадают в ответ (округление выдаёт ошибку на нечисловых значениях), будущие точки отсекаются в SQL и в модуле.
- Ограничения: оценка считается по запросу и пока не сохраняется (это T3); диапазоны учитывают только разброс точек; выброс в первой точке окна не распознаётся.
- Не проверено: запуск из CMD/PowerShell (проверялось в Git Bash).
