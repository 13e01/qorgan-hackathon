## 4. Предположения (проверить)

| ID | Предположение | Чем рискуем, если неверно |
|---|---|---|
| AS-001 | Защита проходит на нашем ноутбуке, локальный запуск допустим | Нужен публичный деплой (резерв: T10-доп.) |
| AS-002 | Интернет на площадке есть, но может быть нестабилен | Карта без подложки — есть офлайн-запас GeoJSON |
| AS-003 | Реальные данные Казгидромета не требуются; симуляция разрешена | Пришлось бы искать открытые данные — сроки не позволят |
| AS-004 | Пользователи и роли нужны в минимальном виде | Если ТЗ требует полноценное управление пользователями — +1–2 ч |
| AS-005 | Нет требований к конкретному стеку технологий | Если стек задан — пересмотр DECISIONS |
| AS-006 | Нет обязательных форматов сдачи (презентация, видео, репозиторий) | Нужно время на материалы — выделено в T10 |
| AS-007 | Защита может быть утром 29.10 | План ставит MVP на вечер 28.10 |
