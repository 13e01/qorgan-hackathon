# Экономическое обоснование QORGAN

> Это оценка для учебного прототипа. Подтверждённой экономии у QORGAN **нет**: система не работала на реальной реке. Все расчёты — с явными допущениями; цифры чужих исследований приведены со ссылками и оговорками.

## 1. Кому это нужно

| Пользователь | Задача | Что даёт QORGAN |
|---|---|---|
| Дежурная служба ДЧС области / района | видеть обстановку по всем постам, вовремя реагировать | карта, журнал предупреждений с отметками, запас времени по каждому пункту |
| Акиматы районов и сельских округов ниже по течению | заранее готовить эвакуацию, технику, мешки | «опасный уровень через ≈ N ч» по своему пункту |
| Водохозяйственные организации (водохранилища) | понимать, как сброс и приток пойдут вниз | цепочка станций и модель распространения волны (после калибровки) |
| Наблюдатели / жители (гость) | видеть опубликованные предупреждения | публичная карта и активные предупреждения без входа |

QORGAN **не заменяет** Казгидромет и государственную систему оповещения. Он работает как надстройка: собирает данные постов в одном окне, объясняет оценку и считает запас времени.

## 2. Сколько стоит внедрение (оценка на один речной бассейн)

| Статья | Оценка | Основа |
|---|---|---|
| Программное обеспечение | 0 тг лицензий | открытый стек: Node.js, SQLite, React, MapLibre, OpenStreetMap |
| Сервер | ≈ $4–6 в месяц (≈ 25–35 тыс. тг в год) | DigitalOcean $4–6, Hetzner CX23 €5,99 ([DO](https://www.digitalocean.com/pricing/droplets), [Hetzner](https://www.hetzner.com/cloud/cost-optimized/)) |
| Подключение существующих постов | работа интегратора, без закупки датчиков | любой пост, который умеет отправить HTTP-запрос с токеном (`POST /api/telemetry`) |
| Новый недорогой пост (там, где поста нет) | ≈ $100–250 за узел без монтажа | **наша оценка** BOM: ультразвук/ToF $10–60 + ESP32 и LoRa/GSM $10–25 + солнечная панель и АКБ $30–80 + корпус IP67 $30–100. Исследования с ценой не найдено |
| Промышленный радарный уровнемер (для сравнения) | ≈ £517–€618 только датчик | VEGAPULS C 11 у дистрибьютора RS ([RS UK](https://uk.rs-online.com/web/p/level-sensors/2067072)) |
| Оповещение в Telegram | 0 тг | Telegram Bot API бесплатен, есть лимиты скорости ([Telegram](https://core.telegram.org/bots/faq)) |
| SMS (опция) | ≈ 10–20 тг у местных агрегаторов [непроверено]; $0,34 через Twilio | [Twilio KZ](https://www.twilio.com/en-us/sms/pricing/kz) |

**Пример (допущения команды):** 1 сервер + 4 подключённых существующих поста + 6 новых недорогих постов.
- Оборудование: 6 × $250 = **$1 500** (верхняя граница нашей оценки) + монтаж (не оценивали).
- Эксплуатация: сервер ≈ $72 в год, связь GSM для 6 узлов — по тарифу оператора (не оценивали), Telegram — 0.

## 3. Чем отличается от существующих решений

| | Казгидромет (бюллетени) | GloFAS / Flood Hub | QORGAN |
|---|---|---|---|
| Данные | своя сеть постов, 2 замера в сутки | глобальные модели и спутники | любые посты, которые подключат, в реальном времени |
| Форма прогноза | окна дат пика по створам | гидрограф, вероятности, до 15 сут | запас времени до порогов по каждому пункту, диапазон, проверка на истории |
| Журнал реакции оператора | — | — | предупреждения с отметками, автором и историей |
| Стоимость для района | — (государственный сервис) | бесплатный просмотр | сервер ≈ $5 в месяц |
| Язык | рус./каз. | англ. | каз./рус./англ. |

[вывод] QORGAN не соревнуется с ними в точности — он соединяет их прогнозы, местные посты и действия дежурных в одном рабочем месте.

## 4. Что может дать раннее предупреждение (исследования, не наши данные)

- **Hallegatte, World Bank, 2012 (WP 6058):** для развивающихся стран системы раннего оповещения дают $4–36 млрд выгод в год при затратах около $1 млрд, **отношение выгод к затратам 4–36**. Это самый проверяемый источник. [факт] [EconPapers](https://econpapers.repec.org/RePEc:wbk:wbrwps:6058)
- **ВМО / Global Commission on Adaptation:** «24 часа предупреждения могут снизить ущерб на 30 %», выгоды/затраты 1:9. [факт] [WMO](https://wmo.int/node/25794). **Оговорка:** PreventionWeb возводит цифру «30 %» к одной оценке 1970 г. по одному бассейну в США и не советует использовать её как общую статистику [непроверено]. Мы её на защите **не используем** как аргумент.
- Масштаб ущерба 2024 г. для ориентира: только на восстановление разрушенного жилья по стране — около 237 млрд тг ([Kazinform](https://qazinform.com/news/kazakh-president-briefed-on-governments-work-to-address-impact-of-floods-7e8fd1)).

**Как честно говорить на защите:** «Стоимость эксплуатации — порядка нескольких тысяч тенге в месяц за сервер. Исследования Всемирного банка оценивают выгоды систем раннего оповещения в 4–36 раз выше затрат. Сколько сэкономит именно QORGAN, можно узнать только после калибровки на реальных данных и пилота в одном районе».

## 5. Модели использования

1. **Пилот в одном районе** (например, ниже Сергеевского водохранилища): подключение существующих постов + 2–3 недорогих поста в слабых местах; сезон половодья — проверка прогноза по реке на фактических данных.
2. **Областной сервис** для дежурной службы ДЧС: один сервер, все посты бассейна Есиля, учётные записи для районов.
3. **Учебный стенд** для колледжей и школ: симулятор и прозрачная модель для уроков по ЧС (работает без интернета, кроме подложки карты).

## 6. Что не оценивали

Монтаж постов, связь GSM/LoRa в конкретных сёлах, обслуживание датчиков зимой (лёд), стоимость калибровки модели специалистом-гидрологом, юридическое согласование с ДЧС.
