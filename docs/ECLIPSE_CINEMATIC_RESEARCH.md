Дата: 29.10.2026. Ветка `revolution/qorgan-eclipse`. Источники просмотрены во встроенном браузере (отдельные страницы
примеров, а не только каталог); библиотеки — по npm, GitHub API, bundlephobia и официальной документации.

## 5. Важная находка о Windows

И встроенный браузер, и Edge на этом компьютере сообщают `prefers-reduced-motion: reduce`. Скорее всего, в Windows
выключены «Эффекты анимации» (Параметры → Специальные возможности → Визуальные эффекты). Поэтому прототипы по умолчанию
показываются **без анимации** (так и должно быть для пользователей с этой настройкой). Чтобы оценить движение, нажмите
**«С анимацией»** на панели прототипа внизу экрана.
