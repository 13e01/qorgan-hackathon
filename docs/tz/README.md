# Официальное ТЗ организаторов

Положите сюда 4 фотографии технического задания с понятными именами:

```
docs/tz/tz-1.jpg
docs/tz/tz-2.jpg
docs/tz/tz-3.jpg
docs/tz/tz-4.jpg
```

Либо просто перетащите фото в чат Claude Code Desktop.

После этого Claude Code:
1. прочитает каждое фото и перепишет текст в `docs/tz/TZ-TRANSCRIPT.md` (с пометками, что читается неуверенно);
2. сверит требования в [`docs/REQUIREMENTS.md`](../REQUIREMENTS.md) по чек-листу из раздела 7;
3. исправит архитектуру и план, если ТЗ противоречит текущим решениям.

Если на фото что-то плохо видно — лучше переснять, чем угадывать.
