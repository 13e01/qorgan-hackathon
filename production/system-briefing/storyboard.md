# QORGAN · System Briefing — раскадровка

60,0 с · 1920×1080 · 60 к/с. Один дубль записи (`capture/take4`), три монтажных отрезка: главная → рабочая система → главная.
Время в ролике — `O` в `tools/timeline.mjs`; время в записи — метки `events.json`. Камера — ключевые кадры с плавностью
easeInOut (кубическая); масштаб `z` — во сколько раз увеличена страница 1920×1080; запись снята с плотностью 1,5
(кадры 2880×1620), поэтому при `z ≤ 1,5` текст остаётся резким.

Проверка реализуемости: до финального монтажа все кадры раскадровки отрендерены по отдельности
(`render.mjs --still=…`) и просмотрены на контактных листах; найдено и исправлено: пометка «Учебная демонстрация»
закрывала уведомление о Соколовке (перенесена влево), первый кадр обрезал заголовок (камера начинается только на реке),
кнопка «История» исчезает после обработки (сцена убрана из съёмки).

**Чего нет в ролике и почему:** «Прогноз по реке» в режиме одного внешнего датчика не показывает запас времени
(нет данных верхних станций; строка «в ближайшие 0 ч не ожидается»), поэтому раздел не снимался — чтобы показать его
честно, нужен прогон встроенного симулятора, а это вторая история и не помещается в минуту. Связь «угроза идёт вниз
по течению» показана через настоящее предупреждение Соколовки.
