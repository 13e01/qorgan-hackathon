## Что изучено и какие решения приняты

| Источник | Что взято | Решение |
|---|---|---|
| [Remotion — основы](https://www.remotion.dev/docs/the-fundamentals), [лицензия](https://github.com/remotion-dev/remotion/blob/main/LICENSE.md) | Идея «кадр = функция от номера кадра», композиции с `durationInFrames/fps/width/height`, рендер через headless-браузер | Принцип взят полностью (`edit/compositor.html` → `renderFrame(k)`), сам Remotion не ставили: это React-проект с отдельной загрузкой Chromium (~сотни МБ), а для одной минуты хватает 300 строк без зависимостей. Лицензия Remotion бесплатна для частных лиц и компаний до 3 сотрудников — не ограничивала бы, но не понадобилась |
| [FFmpeg filters](https://ffmpeg.org/ffmpeg-filters.html) — `loudnorm`, `silenceremove`, `blackdetect`, `freezedetect` | EBU R128: два прохода (`measured_I/TP/LRA/thresh` + `linear=true`) | Итог −16 LUFS (типично для показа с ноутбука/проектора и онлайн-видео), пик ≤ −1,5 dBTP |
| [Playwright — запись видео](https://playwright.dev/docs/videos) | `recordVideo` пишет видео размером вьюпорта, по умолчанию вписанным в 800×800, сохраняет при закрытии контекста | Для 1920×1080 60 к/с с резкими крупными планами этого мало; Playwright — ещё и зависимость с загрузкой браузеров. Используем тот же протокол CDP напрямую: screencast до ~60 к/с при плотности 1,5 (кадры 2880×1620) |
| [Motion — функции плавности](https://motion.dev/docs/easing-functions) | `easeIn/easeOut/easeInOut`, `cubicBezier`, `linear` | Камера и курсор — `easeInOut` (кубическая), медленный наезд во время подъёма — `linear`; курсор идёт по дуге Безье, без телепортации |
| motionsites.ai, navbar.gallery | **Не открывались** в этой сессии (приоритет отдан записи и проверке). Использованы общие принципы роликов о продуктах: один язык камеры, крупный план там, куда смотреть, мало титров | Четыре главы с короткой меткой, одна постоянная пометка «Учебная демонстрация», финальная карточка; чужие кадры, музыка и элементы не использовались |

Внешние материалы (чужая музыка, видео, иконки, логотипы партнёров) в ролике **не используются**.
