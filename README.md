# QORGAN

**Интеллектуальная система мониторинга и раннего предупреждения паводков** в Северо-Казахстанской области (р. Есиль / Ишим). Прототип для хакатона 28–29 октября 2026.

> ⚠️ Все показания в системе — **демонстрационные (симулированные)**. Станции виртуальные, пороги учебные. Реальная только география (OpenStreetMap).

## Что умеет (план)
- Карта СКО с рекой Есиль и 4 виртуальными гидрологическими станциями: Сергеевка → Явленка → Петропавловск → Соколовка.
- **Симуляция паводковой волны**: подъём воды у истока и её движение вниз по реке с задержкой; несколько сценариев, пауза, шаг, сброс, ручной ввод, воспроизводимость по seed.
- Расчёт риска (низкий / средний / высокий), скорости подъёма, тренда и времени до опасного порога — с объяснением причин и оценкой неопределённости. Прозрачный алгоритм, не ML.
- Автоматические предупреждения без дублей, подтверждение оператором, история статусов.
- Графики и история измерений, администрирование станций и порогов, роли operator/admin.
- Интерфейс на қазақша / русском / English.

## Запуск (будет доступен после Phase 1)
Нужно: Windows 11, Node.js 24+, npm 11+.

```bash
npm install
```

```bash
npm run dev
```

Затем открыть http://localhost:5173. Для показа: `npm run build`, затем `npm start` (или `start-demo.bat`) и http://localhost:3000.
